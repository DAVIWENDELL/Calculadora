# Calculadora Web

Aplicação web de calculadora desenvolvida com Python e Flask.

## Funcionalidades

- Adição;
- Subtração;
- Multiplicação;
- Divisão;
- Tratamento de divisão por zero.

## Tecnologias

- Python
- Flask
- HTML
- CSS
- JavaScript

## Como executar

Instale as dependências do projeto e execute a aplicação Flask conforme a configuração local do repositório.
